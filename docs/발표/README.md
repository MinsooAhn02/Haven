# Haven 발표 자료

현재 발표에 사용할 자료는 아래 파일입니다. PPT는 전체 14장으로 구성되어 있으며, 기술과 구성은 구현 전 계획입니다.

- [발표 PPT](Haven_프로젝트_계획서.pptx)
- [슬라이드별 발표 대본](발표대본.md)
- [전체 14장 미리보기](미리보기/전체슬라이드.png)
- [주요 장표 미리보기](미리보기/주요슬라이드.png)

## 폴더 구조

```text
발표/
├─ Haven_프로젝트_계획서.pptx   현재 발표 PPT
├─ 발표대본.md                현재 PPT의 14장 순서에 맞춘 대본
├─ 미리보기/
│  ├─ 주요슬라이드.png
│  └─ 전체슬라이드.png
├─ src/
│  ├─ build_haven.cjs         현재 PPT 제작 소스
│  └─ manifest.json           생성된 장표 목록과 배치 정보
└─ archive/
   ├─ 이전초안/               이전 PPT와 당시 미리보기
   └─ 검토샘플/               1차, 2차, 3차 검토 샘플
```

## 이전 자료와 구분

현재 PPT에는 `샘플`, `초안`, `최종` 같은 단계 표시를 파일명에 붙이지 않습니다. 과거 초안과 부분 장표는 [아카이브](archive/README.md)에서 구분해 보관합니다. 검토 샘플의 장 번호는 당시 아웃라인 기준이므로 현재 전체본과 다를 수 있습니다.

## 제작 소스

`src/build_haven.cjs`는 pptxgenjs와 로컬 테마 적용 도구를 사용하는 제작 소스입니다. 출력은 이 폴더의 `Haven_프로젝트_계획서.pptx`이며 장표 목록은 `src/manifest.json`에 기록합니다. 새로 생성할 때는 해당 의존성이 준비된 환경을 사용하고, 내용이 바뀌면 실제 PowerPoint 렌더링과 미리보기 및 대본도 함께 확인합니다.
