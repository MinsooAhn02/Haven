# 이전 발표 자료

현재 사용할 자료는 [Haven 프로젝트 계획서](../Haven_프로젝트_계획서.pptx)입니다.

| 폴더 | 보관 내용 |
|---|---|
| [이전초안](이전초안/) | 이전 PPT 파일과 당시 표지/내용 미리보기 |
| [검토샘플](검토샘플/) | 1차 표지/개요/AWS 배치, 2차 연결/구현/복원, 3차 구성/권한/협업 검토 자료 |

이 폴더는 과거 자료를 보존하는 용도입니다. 기존 PPT의 내용을 수정하거나 삭제하지 않았습니다. 단계별 샘플은 전체 발표본이 아니며 당시 목차를 사용하므로, 현재 발표에는 위 링크의 PPT와 [현재 대본](../발표대본.md)을 사용합니다.
