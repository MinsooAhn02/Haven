# Lessons

- Keep workflow docs focused on owner handoffs and time sequence; preserve the agreed architecture, roles, and four rounds instead of broadly rewriting them.
- 사용자가 구현과 마무리를 요청하면 로컬 수정에서 멈추지 않는다. 승인된 범위의 검증·커밋·푸시·병합까지 수행하고 실제 원격 상태로 완료를 확인한다.
- 병합·문서 정리 완료와 담당 구현 완료를 구분한다. 앱 인계가 없어도 독립적인 CLI CI·실행 검증처럼 진행할 수 있는 담당 작업은 먼저 수행한다.
