## 7. 지켜야 할 규칙 (팀 공통)

- 비밀번호·키·토큰을 Git, 문서, 메시지에 쓰지 않는다. 시험 계정 비밀번호는 입력으로만 다룬다.
- `main`에는 PR로만 반영한다. force push는 하지 않는다. 개인 폴더 `구민철/` 안에서만 고친다.
- PR에는 실제 실행한 명령과 결과, 일부러 실패시킨 거부 시험, 확인하지 못한 것을 구분해서 적는다. PR 본문은 비우지 않는다.
- "완료"는 실제로 돌려 본 것만 쓴다. 문서 작성이나 PR 병합은 실제 서버 동작의 증거가 아니다.
- 운영 사이트(`https://orchestration-haven.cloud`)에 비정상·공격성 요청을 임의로 보내지 않는다. 승인된 시험은 권혁민 담당이다.
- AWS 접근은 읽기 전용 IAM 사용자로만 한다(root 금지). 자원 삭제·변경은 하지 않는다.
