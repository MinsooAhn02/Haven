## 3. 오탐·미탐 정리

### 3.1 오탐 (정상 요청이 규칙에 걸림)

| 규칙 (그룹) | 정상 요청 | 확인 방법 | 영향 (Block 시) |
|---|---|---|---|
| `SizeRestrictions_BODY` (Common) | 8KB 넘는 정상 첨부 업로드 | 누적 로그 27건 + 11/13 구간 8건, 2 MiB 업로드 재현 | 정상 첨부 업로드 차단 |
| `SQLi_BODY` (SQLi) | 비밀번호에 `!`→`@`→`#`이 영문·숫자 바로 뒤에 이어진 로그인·가입 | 11/16·17 로그인·가입 8건, 같은 모양의 비밀번호로 3회 재현 | 해당 비밀번호 사용자의 로그인·가입 차단 |
| `CrossSiteScripting_BODY` (Common) | XMP 메타데이터가 앞부분에 있는 정상 PDF 업로드 | 11/13 팀원 업로드 2건, 시험용 PDF로 재현 | Word·Acrobat PDF 업로드 차단 |
| `NoUserAgent_HEADER` (Common) | 팀 점검 스크립트(User-Agent 없음) | 누적 로그 KR 반복 요청, 조장 확인(11/19) | 점검 스크립트 403 |

- 그 밖의 정상 요청(글·공유·해제·업로드·다운로드·삭제·로그아웃, 정상 헤더, SQL·HTML 설명 글, 메타데이터 없는 PDF)은 **규칙 매칭 0건**이었다.

## 4. 규칙 그룹별 Block 판단 (혁민 11/20 확정)

| 규칙 그룹 | 지금 | 판단 | 예외 (Count 유지 또는 주소별 제외) | 근거 요약 |
|---|---|---|---|---|
| KnownBadInputs | Count | **Block** | 없음 | 스캐너·헤더 공격만 매칭, 정상 요청 0건 |
| SQLi | Count | **Block + 예외 1** | 로그인·가입 주소에서만 `SQLi_BODY` 제외 | `!@#` 비밀번호 오탐. 로그인 폼은 Django ORM이라 SQL 주입 경로 없음 |
| Common | Count | **Block + 예외 3** | `SizeRestrictions_BODY` Count 유지, `NoUserAgent_HEADER` Count 유지(점검 스크립트에 User-Agent를 붙이면 Block), 첨부 업로드 주소에서만 `CrossSiteScripting_BODY` 제외 | 업로드·PDF·점검 스크립트 오탐 |

- 적용 순서(판단안 5장): KnownBadInputs → SQLi → Common, 단계마다 전후 시험.
- 예외 때문에 WAF가 보지 않는 부분(로그인·가입의 SQL 문자열, 첨부 업로드의 XSS, 8KB 뒤 본문)은 **앱 방어에 의존**한다(판단안 4장).

## 7. 새로 확인된 위험: WAF 로그의 본문 조각 (SEC-53)

- 규칙에 걸린 요청은 WAF 로그 `matchedData`에 **요청 본문 일부가 평문으로** 남는다. 가림 설정은 헤더·URI·쿼리만 되고 본문은 안 된다. 11/16·17 로그인 8건의 로그에 11/16·17 로그인·가입 8건의 로그에 비밀번호가 남아 있었다(값은 이 문서에 적지 않는다).
- **조장 결정(11/20):** 보관 30일, 30일이 지난 원본은 혁민이 저장소 밖에 개인 보관, 조회는 혁민 정책만. 분석할 때 `matchedData`를 문서에 옮기지 않는다.
- 로그인·가입의 `SQLi_BODY` 예외는 **차단만 막을 뿐 기록은 막지 않는다.** `SQLi_BODY`는 Count로 남아 계속 WAF 로그에 기록되므로, 예외를 적용해도 **이 위험은 줄지 않는다**(혁민 확인, 조장 11/20 지적). 보관 기간·조회 권한 제한(위 조장 결정)으로 관리한다.

## 9. 한계

- 혁민 보고와 시험결과 문서, 조장 운영기록을 옮긴 것이다. 구민철이 WAF 로그를 직접 조회하거나 시험을 다시 실행하지 않았다.
- 시험 요청 기준의 관찰이며 **방어율이 아니다.** 관리형 규칙의 탐지는 시험 문자열에 따라 달라진다.
- 혁민 CLI의 판정 칸은 `manual_required`(UNKNOWN)이고, PASS는 HTTP 결과와 로그를 보고 사람이 내렸다(혁민 보고).
- ALB 앞 WAF는 본문 앞 8KB만 검사한다.
- 원본 로그·결과(`output/`)는 계정 번호와 IP가 들어 있어 저장소에 없다.
