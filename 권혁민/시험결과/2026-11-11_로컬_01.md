## 4. 실패 및 불일치 케이스

**시험 케이스:** HTTP 기대값 불일치와 시험 실행 오류는 없음.

| 케이스 ID | 기대값 | 실제값 | request_id |
|---|---|---|---|
| 해당 없음 | — | — | — |

**별도 복구 단계:** 2건의 오류로 전체 복구 미완료.

| 복구 케이스 ID | 연관 시험 케이스 | 오류 내용 | request_id |
|---|---|---|---|
| `CLEANUP-P2-C` | `SH-05-A-GRANT-P2-C` | 소유자의 공유 목록을 HTTP 200 HTML로 확인하지 못했습니다 | `827cd530-64f9-41a8-bf87-df61279862df` |
| `CLEANUP-P1-B` | `SH-01-A-GRANT` | 소유자의 공유 목록을 HTTP 200 HTML로 확인하지 못했습니다 | `24b34c5c-c201-4f28-b88d-426a13d028af` |

- `CLEANUP-C-ACTIVE`, `CLEANUP-B-ACTIVE`, `CLEANUP-A-ACTIVE`의 복구 HTTP 응답은 모두 `302`로 기대값과 일치함.
- 공유 해제 복구 2건은 소유자의 공유 목록을 HTTP `200` HTML로 확인하지 못해 **실제 공유 해제 POST 요청은 전송되지 않음** (`request_attempted=false`). 관련 조회 기록에는 HTTP `302` 응답이 나타남.
- 따라서 복구 오류 2건은 **시험 144건의 `FAIL`/`ERROR` 집계에 포함되지 않으며**, 공유 관계 최종 상태를 DB에서 확인해야 함.

## 5. 비고

- 실제 Django 로컬 서버를 대상으로 수행했으며, AWS WAF 검증과 WAF/Django 로그 상관분석은 이 결과에 포함되지 않음.
- **복구가 미완료**이므로 재시험 전에 DB의 공유 관계와 사용자 활성 상태, 게시글 변경·생성 상태를 별도 확인할 필요가 있음. 실제 잔존 공유 관계 유무는 이 결과만으로 확정할 수 없음.
- `cleanup_http_requests=5`는 도구가 기록한 복구 관련 HTTP 요청 수이며, 복구 결과 5개 모두가 공유 해제 POST를 실행했다는 의미는 아님.
