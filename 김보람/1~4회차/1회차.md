# 1회차 작업 기록 — 계정·보안 기본 점검

**담당:** 김보람 (AWS 계정·IAM·비용 관리)  
**기록 방식:** 실제 확인한 내용을 날짜순으로 작성함. 날짜가 명확하지 않은 초기 작업은 11월 6일까지의 점검으로 표시함.

## 2026-11-06 — 시험용 IAM 계정·권한 점검 및 운영 방향 검토

### 시험용 IAM 계정과 MFA
- 시험용 IAM 사용자 `sherlocked`를 별도 생성하고 `AWSBillingReadOnlyAccess`(비용 조회 정책)를 부여함. 액세스 키는 **0개**로 확인함.
- 인증 앱을 이용해 IAM 사용자 MFA를 등록함. 재로그인 때 MFA 6자리 인증을 요구하는 것을 확인하고 로그인에 성공함.
- 루트 계정과 IAM 사용자의 MFA가 서로 별도로 관리됨을 확인함.

### 접근 허용·거부 확인
- `sherlocked`로 AWS 콘솔 로그인 후 결제 및 비용 관리 화면 진입과 당시 실제 사용 요금 **$0.00** 조회에 성공함.
- `iam:GetUser` 권한 부족으로 IAM 사용자 정보 조회가 거부됨. Resource Explorer 검색도 권한 거부 확인.
- 비용 관리 화면의 일부 예상 비용 및 비용 이상 항목 조회는 권한 부족으로 거부됨. **비용 읽기 정책이 모든 비용 관련 기능을 허용하는 것은 아님**을 기록함.
- 위 결과는 시험용 사용자의 화면 확인이며 다른 팀원에게 권한이 적용됐다는 뜻이 아님.

### 초기 자원·비용 점검
- 서울 리전(`ap-northeast-2`)에서 당시 EC2 인스턴스 **0대**, EBS 볼륨 **0개**, 스냅샷 **0개**로 확인함.
- 당시 AWS 크레딧 잔액 **$120**, 사용 요금 **$0.00**, $1 예산 알림과 이메일 인증 상태를 확인함.
- 다른 리전과 모든 서비스의 자원까지 점검한 것은 아님.

### 네트워크·접근 정책 검토
- 이민성님의 네트워크 설계서 5장(출구 비용 비교)과 6장(인계 요청)을 검토함.
- 서울 리전 사용, NAT Gateway 1개 및 S3 Gateway Endpoint 1개 구성을 제안함. **당시에는 제안 단계이며 승인·실제 생성 완료가 아님**.
- 담당별 필요 권한 초안을 정리함: 민성(서버·네트워크·제한된 PassRole), 민수(배포·SSM·백업), 혁민(보안 로그/WAF 조회), 보람(IAM·비용). 푸른·요찬은 당시 별도 AWS 콘솔 접근 필요 여부가 미확정.
- 루트 계정이나 비밀번호·MFA 비밀값을 GitHub에 기록하지 않도록 구분함.

## 2026-11-07 — 1회차 현황 인계

- 시험용 IAM MFA·허용/거부 시험·크레딧 및 비용 알림 점검 현황을 팀에 공유함.
- 서울 리전, NAT 1개+S3 Endpoint 1개 추천과 함께 당시 미확정 항목(팀 예산·비용 부담, 개인별 권한, 운영 시간, 종료 담당)을 구분해 정리함.
- **PR #8**로 1회차 기록 및 운영 결정 현황을 제출함. 당시 제출 직후에는 검토 대기 상태였음.
- 상세 권한 적용과 서버 시험은 담당자 승인 및 실제 인프라 구축 이후 진행할 항목으로 남김.

## 2026-11-08 — 루트 보안 및 복구 정보 재확인

- 루트 계정 보안 자격 증명에서 **가상 MFA 장치 1개 등록** 확인. 시험용 IAM 사용자 MFA와 별개의 장치/설정으로 기록함.
- 루트 계정의 복구 이메일 및 기본 전화번호·주소가 등록된 것을 확인함.
- **대체 연락처 미설정**, 예비 MFA 장치 **미검증**, 이메일·전화번호를 이용한 **실제 계정 복구 시험 미실시** 상태로 남김.
- 콘솔이 서울 리전으로 선택된 상태를 확인함. 다른 리전 자원 존재 여부는 계속 미확인.
- **PR #8은 11/07 main 병합 완료**된 것으로 후속 확인함. 팀의 예산·운영·권한 결정은 별도의 승인 결과를 따라야 함을 기록함.

## 1회차 종료 시 확인되지 않은 사항

- 루트 예비 MFA·복구 절차의 실제 시험, 다른 리전의 자원 조회
- 팀원별 IAM 권한 최종 승인 및 실제 업무용 계정의 허용·거부 시험
- NAT·S3 Endpoint의 실제 적용 및 서버 구축 후 연결 검증
