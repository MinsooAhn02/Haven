### 1. 시험용 SG 삭제 권한 제한
- 고객 관리형 `Haven-Minsung-Delete-Policy`를 AWS 콘솔에서 수정해 **업데이트 성공**을 확인함.
- 시험용 EC2 영구 삭제 범위(`Project=Haven`, `Owner=minsung`, `Name=haven-test*`)는 유지함.
- `ec2:DeleteSecurityGroup`은 **`Project=Haven`과 `Name=haven-sg-test` 태그 조건을 모두 만족하는 SG**로 제한함. 운영용 `haven-sg-web`·`haven-sg-db`·`haven-sg-alb`를 임의 삭제하지 않도록 범위를 축소한 것임.
- [15번 정책 JSON](../JSON/15_Minsung_DeleteSecurityGroup_Policy.json)을 갱신함. 이는 AWS의 정책 저장 확인이지 실제 삭제 허용/거부 테스트 완료가 아님.
- 실제 시험용 SG 삭제 허용·운영 SG 삭제 거부 시험과 다른 정책을 통한 우회 가능성은 민성님 점검 대기. 조회 당시 `haven-sg-test` SG는 목록에서 발견되지 않았음.

### 2026-11-12 — 민성님 WAF 야간 유지 비용·IAM 권한 검토 및 답변
- **요청 배경:** ALB 야간 유지 조건에서 혁민님 PR #80의 WAF 구성(기존 예상: Web ACL 1개 + 규칙 2개 / 실제 PR: Web ACL 1개 + AWS 관리형 규칙 그룹 3개)으로 인한 추가비용 및 IAM 정책 검토 요청.
- **PR #80 기준 구성:** Web ACL `haven-web-acl` 1개, 관리형 규칙 그룹 `AWSManagedRulesCommonRuleSet`, `AWSManagedRulesSQLiRuleSet`, `AWSManagedRulesKnownBadInputsRuleSet` 3개, Count 모드, WCU 1,100. Web ACL 3개가 아니라 **Web ACL 1개 + 규칙 그룹 3개**임.
- **비용 계산(일반 AWS WAF 기본요금 가정):** Web ACL $5/월 + 규칙 그룹 $1/개/월 × 3 = **약 $8/월**. 기존 2개 규칙 그룹 구성($7/월) 대비 **월 약 $1 증가**. 야간·주말 108시간(평일 12시간 × 5일 + 주말 48시간) 해당분은 월 730시간 기준 단순 환산 시 **약 $1.18**. 이는 야간·주말분의 기본요금 환산이며 WAF가 상시 존재할 경우 **월 전체 기본요금 $8**이 발생함. 실제 요청량, 유료 관리형 규칙 추가 선택 여부, CloudWatch 로그, ALB 관련 요금은 별도. 1,100 WCU는 1,500 WCU 기본 포함 범위 내.
- **야간 유지 의견:** 추가 기본요금이 월 약 $1인 점을 고려하면 **WAF 야간 유지 방안에 동의**하되, 실제 과금 및 로그 사용량은 계속 확인.
- **`ManageReferencedManagedRuleSets` 추가 이유:** 혁민님이 Web ACL 생성 과정의 `CreateWebACL` 권한 오류를 보고하며 관리형 규칙 세트 참조에 필요한 리소스 권한 보완을 요청하여 추가함. AWS WAF IAM 리소스 형식 `managedruleset`은 관련 작업에서 사용될 수 있음. 그러나 정책에 기재된 `arn:aws:wafv2:ap-northeast-2:ACCOUNT_ID_MASKED:regional/managedruleset/*/*`의 **계정 ID는 Haven AWS 계정 번호로 올바르지만**, AWS 제공 관리형 규칙 그룹에 대해 해당 계정 범위를 쓰는 것이 실제 필요한 권한과 일치하는지는 아직 미검증. PR #80에는 `create-web-acl` 성공이 기록되어 있으나, **그 성공이 이 특정 리소스 권한 덕분인지까지는 확인되지 않음**. 임의 변경하지 않고 실제 IAM 평가/오류 내역으로 검증 필요.
- **ALB 연결 권한:** `wafv2:AssociateWebACL`, `wafv2:GetWebACLForResource` 관련 리소스 범위는 실제 ALB 연결 시험으로 검증 필요. 26번 민성 WAF 정책에 ALB 연결·해제·조회용 권한을 보완하고 ALB 범위를 `haven-alb`로 제한한 상태. 연결 과정에서 `AccessDenied`가 발생하면 **거부된 작업과 ARN을 먼저 확인**하고 ALB ARN 등을 최소 범위로 추가 검토.
- **완료 구분:** 본 항목은 비용 및 권한 **검토·답변 기록**임. Web ACL–ALB 실제 연결 성공, 정책 허용/거부 시험, WAF 실사용 요금 확정으로 처리하지 않음.
