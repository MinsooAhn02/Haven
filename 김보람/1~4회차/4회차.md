## 2026-11-17 — IAM JSON 계정 번호 변수명 통일

- **수정 대상:** `김보람/JSON/`의 02·04·06·07·08번 정책 JSON 5개.
- 기존 계정 번호 자리표시자 `${AWS_ACCOUNT_ID}`를 `${ACCOUNT_ID}`로 통일함. IAM Action·Resource의 계정 번호 외 부분·Condition 등 권한 설정은 변경하지 않음.
- 관련 문서 `김보람/TODO.md`의 작업 항목을 완료로 정리하고, `docs/조장_운영기록/2026-11-16.md`의 해당 변수 표기도 정리함.
- **검증:** 수정한 5개 JSON의 문법 검사 통과 및 7개 수정 파일에 기존 변수명 잔존하지 않는 것을 재확인함. 실제 AWS IAM 정책은 수정하지 않음.
- **반영 위치:** GitHub `Boram` 브랜치의 기존 PR [#127](https://github.com/MinsooAhn02/Haven/pull/127)에 자동 반영됨. 별도 PR 생성·main 병합은 수행하지 않음.

## 2026-11-17 — 12번 IAM 인프라 정책의 최소권한 범위 검토 요청

- **검토 대상:** [12번 `Haven-Minsung-Infra-Policy`](../JSON/12_Minsung_Infra_Policy.json)의 `ConfigureHavenInfrastructureInSeoul` Statement.
- VPC·서브넷·라우팅·보안 그룹 관련 설정 작업 9개가 `Resource: "*"`로 허용되어 있고, `aws:RequestedRegion=ap-northeast-2` 조건만 적용되어 있음을 확인함.
- 서울 리전으로는 제한되지만 Haven 프로젝트 리소스만으로 한정된 것은 아니므로, 담당 업무에 필요한 범위인지 및 리소스 ARN·태그 조건으로 추가 제한이 가능한지 확인이 필요함.
- 실제 네트워크 운영 영향이 있을 수 있어 **정책을 임의 수정하지 않고**, 민성님께 기존 [PR #127 댓글](https://github.com/MinsooAhn02/Haven/pull/127#issuecomment-6935037215)로 검토를 요청함.
- **상태:** 담당자 검토 결과 대기. AWS IAM 정책 및 12번 JSON 변경 없음.

## 2026-11-17 — 시험 메일 스팸함 도착 원인 및 개선 의견

- **관련 기록:** 구민철님 [PR #117](https://github.com/MinsooAhn02/Haven/pull/117) — EXT-03 시험 메일은 실제 도착했으나 네이버 스팸함으로 분류됨. 메일 원본에서 DKIM 인증 통과 확인.
- **수신 측 설정 확인:** 네이버 메일의 '보내는 사람의 주소가 주소록에 없으면 스팸으로 자동 분류' 항목이 활성화되어 있었음을 확인함. 현재 해당 설정을 해제했으며 `noreply@orchestration-haven.cloud`는 수신 허용 목록에 등록되어 있음.
- **판단:** 네이버 스팸 필터가 분류에 영향을 미쳤을 가능성은 있으나, 원인이 확정된 것은 아님. 설정 변경 후 동일 시험 메일 재수신 결과는 아직 확인하지 않음.
- **조치:** [PR #117 댓글](https://github.com/MinsooAhn02/Haven/pull/117#issuecomment-6935371122)로 수신자 측 설정 확인 내용과 재시험 의견을 전달함. 재시험에서도 스팸함으로 분류되면 DMARC 및 SES 사용자 지정 MAIL FROM 설정을 추가 검토하도록 제안함.
- **상태:** AWS의 DMARC·SES MAIL FROM 설정 변경 없음. 실제 설정 적용 여부는 조장님 결정에 따름.
