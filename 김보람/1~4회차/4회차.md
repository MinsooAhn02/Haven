## 1. IAM 권한 허용·거부 결과 확인

- **SG 삭제 권한(민성님, 11/13):** 시험용 `haven-sg-test` 실제 삭제 허용 1건, 운영용 SG 3개·기본 SG 1개 삭제 DryRun 거부 4건 확인([PR #94](https://github.com/MinsooAhn02/Haven/pull/94)). 실제 시험 결과는 담당자 기록 기준이며 보람이 직접 삭제 시험한 것은 아님.
- **SG 조회 최소권한(민철님, 11/16):** 27번 정책에서 미사용 EC2 인스턴스·서브넷 조회 권한을 제거한 뒤, 민철님 계정으로 점검 도구 0.3.1 실제 실행. `COMPLETE`, PASS 11 / FAIL 0 / ERROR 0, 종료 코드 0, `AccessDenied` 없음. **11/23 정식 SG 점검을 대신하는 결과는 아님.**
- **WAF 연결 상태 조회(민성님, 11/16):** 기존 `GetWebACLForResource` 거부 오류 보완 후 `haven-alb`에 연결된 `haven-web-acl` 조회 성공([민성 TODO](../../이민성/TODO.md)).
- **DB 로그 조회(혁민님, 11/16):** `/haven/db` 대상 `logs:FilterLogEvents` 권한을 최소 범위로 추가한 후, 혁민님 계정에서 DB 로그 조회 성공([PR #116 댓글](https://github.com/MinsooAhn02/Haven/pull/116#issuecomment-6906232626)).
- **남은 시험:** 민성님의 시험용 EC2 영구 삭제 허용·운영 EC2 삭제 거부 확인 및 일부 비허용 대상 시험은 완료 근거가 없어 미완료 유지. 12번 인프라 정책의 `Resource: "*"` 범위는 [PR #127 댓글](https://github.com/MinsooAhn02/Haven/pull/127#issuecomment-6935037215)로 운영 담당자 검토 요청 후 판단 대기.

## 2. 잔여 AWS 비용 최종 확인

- 11/16 기준 DB CloudWatch 로그의 **예상 비용**만 따로 검토함: 월 수집량 약 10MB·30일 보존 가정, 요금표 기준 약 **$0.008/월**(무료 사용량 적용 전, 조회 비용 제외). [3회차 기록](3회차.md)에 근거를 작성함.
- 위 추정치는 **AWS 전체 누적 청구액이나 남은 크레딧이 아님**. 최신 계정 전체 실사용액·크레딧 잔액·잔여 과금 자원 비용은 아직 최종 대조하지 않았으므로 완료로 표시하지 않음.

## 3. 자원 보존·종료 목록 취합 및 담당자 확인

- 기존 [AWS 자원 현황·종료 확인 목록](../AWS_자원현황_종료확인목록_2026-11-11.md)을 기초 자료로 보유함.
- 최종 종료 전 EC2·EBS·NAT/EIP·ALB/WAF·CloudWatch·S3·스냅샷 등 자원별 **보존 또는 종료 여부와 담당자 승인**을 최신 상태로 다시 확인해야 함.
- **아직 최종 보존·종료 승인 및 담당자별 실제 종료 완료 결과는 확인되지 않음.** 이 기록을 이유로 AWS 자원을 종료하거나 삭제하지 않음.
