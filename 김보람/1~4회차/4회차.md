# 4회차 작업 기록 — IAM·비용·자원 종료 최종 확인

**담당:** 김보람 (AWS 계정·IAM·비용/자원 관리)

## 진행 상태

4회차는 프로젝트 최종 점검 단계로, 아래 항목의 **최종 확인과 담당자 승인 결과가 아직 남아 있음.** 이전 회차의 IAM 보완·재시험과 11월 17일 후속 작업은 [3회차 기록](3회차.md)에 정리함.

- **IAM:** 담당자별 권한 허용·거부 시험 최종 대조. 시험용 EC2 삭제 허용·운영 EC2 삭제 거부 등 미확인 결과 확인.
  - **12번 IAM `ConfigureHavenInfrastructureInSeoul`의 `Resource: "*"`:** 조장 11/19 결정에 따라 **수정 안 함(위험 수용)**. AWS 정책과 JSON은 변경하지 않음.
- **비용:** AWS 계정 전체 실제 누적 사용액, 잔여 크레딧, 남은 과금 자원·타 리전 자원 최종 확인.
  - **11/18 비용 차이 $1.47:** 11/20(금) **오전 9시에 AWS Billing을 다시 확인할 예정**. 갱신 시차를 고려해 서비스별 요금·사용량과 요약 금액을 비교할 예정. 재확인 전까지 원인은 미확인으로 유지.
- **자원 보존·종료:** [자원·종료 확인 목록](../AWS_자원현황_종료확인목록_2026-11-11.md)의 최신 상태 취합, 각 담당자·조장의 보존/종료 결정 및 실제 종료 결과 확인.
- **최종 기록·PR:** 위 검증 결과를 기록한 후 main 통합용 PR 최종 점검 및 병합 확인.

**참고:** 현재 [PR #127](https://github.com/MinsooAhn02/Haven/pull/127)은 열려 있으나 최종 4회차 점검 및 main 병합 완료를 뜻하지 않음. 보존·종료 승인이 확인되지 않은 AWS 자원은 변경·삭제하지 않음.
