## 1. 오늘 완료한 작업

### AWS 예산 및 비용 관리
- AWS 크레딧 **$120** 중 프로젝트 운영 예산 **$100**, 비상 예비비 **$20**로 계획.
- `Haven-Project-AWS` 비용 예산 $100 생성 및 실제 사용 비용 기준 **$50 / $80 / $95** 경보 설정.
- 예산 관련 이메일 수신자 등록·인증 상태 확인.
- EC2 Web/DB 각 t3.small, EBS gp3 총 40GB, 평일 09:00~21:00 운용 및 NAT 운영 시간을 반영한 예상 비용을 `민수_인계_결정현황.md`에 기록.
- 예상 비용은 계산용 추정치이며 실제 청구 금액이나 자동 차단 설정이 아님.

### EC2 공통 IAM Role 및 인스턴스 프로파일
- EC2 공통 역할 `haven-ec2-ssm-role` 생성.
- 관리형 정책 `AmazonSSMManagedInstanceCore` 연결.
- 인스턴스 프로파일 `haven-ec2-ssm-profile` 생성 및 해당 역할 연결을 AWS CLI로 확인.
- 위 역할에 인라인 정책 `Haven-EC2-SSM-Parameters-Read` 추가:
  - `ssm:GetParameter` — 서울 리전의 `/haven/*` 경로 읽기.
  - DB 비밀번호·Django 비밀키 등 **값 자체는 이 문서에 기록하지 않음**.

### 이민성 담당자의 IAM 사용자·권한
- IAM 사용자 `minsung` 생성 및 콘솔 로그인용 최초 비밀번호 변경 요구 설정.
- 사용자에게 `Haven-Minsung-PassRole-Policy` 연결:
  - `iam:PassRole` 대상은 **`haven-ec2-ssm-role` 한 개**.
  - `iam:PassedToService = ec2.amazonaws.com` 조건으로 EC2 서비스에만 전달 허용.
- `Haven-Minsung-Infra-Policy` 생성:
  - VPC·서브넷·라우팅·보안 그룹·NAT Gateway·EIP·EC2 생성/운영 관련 초안.
  - 서울 리전과 Haven 자원 태그 기준을 반영해 작성.
  - **정책 생성까지 완료했으며 `minsung` 사용자에게는 아직 연결하지 않음.**
  - 실제 AWS 명령 실행·허용/거부 검증은 미수행.

- **PR #29 제출** 및 팀장 검토 요청.

## 3. 현재 상태 및 주의사항

- **IAM Role·프로파일·일부 IAM 정책 생성/연결은 진행했지만, 실제 EC2/VPC 서버 구축과 권한 시험 완료를 의미하지 않음.**
- 인프라 정책은 생성만 했으므로 `minsung`에게 서버 구축 권한이 아직 충분하지 않을 수 있음.
- S3 백업 정책의 버킷 이름은 미확정이며, 버킷명을 받기 전 임의로 실제 S3 자원에 권한을 부여하지 않음.
- IAM 비밀번호·액세스 키·SSM 비밀값은 GitHub와 Discord에 올리지 않음.
- AWS 예산 경고는 자동으로 서버를 중지하거나 NAT를 삭제하지 않음.
