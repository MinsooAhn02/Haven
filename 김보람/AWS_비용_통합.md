#### 3. 크레딧 $20 추가 이유 (간단 설명)

AWS **Billing and Cost Management → Credits** 화면에서 실제 지급 내역을 확인함.

| 크레딧 이름 | 발행 금액 | 시작일 | 만료일 | 상태 |
| --- | ---: | --- | --- | --- |
| AWS Free Tier | **$100.00** | 2026-10-15 | 2027-10-15 | Active |
| Explore AWS: Set up a cost budget using AWS Budgets | **+$20.00** | 2026-11-05 | 2027-10-15 | Active |
| Explore AWS: Launch an instance using EC2 | **+$20.00** | 2026-11-10 | 2027-10-15 | Active |
| **합계** | **$140.00** | | | |

- **이번 $120 → $140 증가분 $20은 2026-11-10 EC2 인스턴스 실행 미션(Explore AWS: Launch an instance using EC2) 완료 보상으로 확인됨.** 추정 아님.
- 앞서 $100 → $120으로 증가한 $20은 2026-11-05 AWS Budgets 비용 예산 설정 미션 보상임.
- 현재 표시된 3개 크레딧의 만료일은 모두 **2027-10-15**이며 상태는 **Active**.

#### 4. Haven 기존 예산과의 관계

- **기존 승인된 프로젝트 운영 예산 $100은 변경하지 않음.** AWS Budgets 경보 $50/$80/$95도 그대로 유지.
- 이전 크레딧 $120은 **운영 $100 + 비상 예비 $20**으로 분리하여 계획했음.
- 새로 지급된 **추가 $20은 현재 미배정 여유 크레딧**으로 기록하고, 운영 예산/비상 예비비 증액 여부는 **팀장 협의 후 결정**.
- 즉, 현재 표시 기준 $140의 크레딧이 있어도 이 문서는 팀 전체 **승인 예산을 $140으로 변경하는 결재 문서가 아님**.

> 주의: 이 자료는 비용 조회·인계 기록임. AWS 자원·정책·예산을 직접 변경하지 않았으며, 금액은 2026-11-11 조회 시점 기준.

## 3. ALB·WAF 야간·주말 예상 비용

### Haven ALB·WAF 평일 야간 및 주말 예상 비용

**기준일:** 2026-11-11  
**담당:** 김보람 (AWS 비용)  
**리전:** 서울 `ap-northeast-2`

#### 계산 조건

- 운영 시간: 평일 09:00~21:00 (12시간)
- 산정 시간: **평일 야간 12시간 × 5일 = 60시간**, **주말 48시간** → 총 **108시간/주**
- ALB 1대 기본요금: **$0.0225/시간**
- ALB용 공인 IPv4 주소 2개 가정: **$0.005 × 2 = $0.01/시간**
- WAF 웹 ACL 1개 + 일반 규칙 2개 가정: **$5 + ($1 × 2) = $7/월** (730시간 기준으로 시간당 환산)
- ALB 사용량(LCU), WAF 요청량, 데이터 전송 및 로그 요금은 아래 기본요금 추정에서 제외

#### 예상 비용 (USD)

| 구분 | 시간 | ALB + IPv4 | WAF | 합계 |
|---|---:|---:|---:|---:|
| 평일 야간 1회 | 12시간 | $0.39 | $0.12 | **$0.51** |
| 평일 야간 5회 | 60시간 | $1.95 | $0.58 | **$2.53** |
| 주말 | 48시간 | $1.56 | $0.46 | **$2.02** |
| **일주일 합계** | **108시간** | **$3.51** | **$1.04** | **$4.55** |

**결론: ALB와 WAF가 평일 야간과 주말에도 유지된다고 가정할 때, 총 기본요금은 주당 약 $4.55로 예상됩니다.**

- WAF가 아직 생성되지 않았거나 사용하지 않는 경우, 동일 시간 기준 ALB+IPv4 기본요금은 **주당 약 $3.51**입니다.
- 실제 WAF 규칙 수 및 사용량에 따라 청구 금액이 달라질 수 있습니다. 이 표는 AWS 청구서 실측값이 아닌 **예상치**입니다.
