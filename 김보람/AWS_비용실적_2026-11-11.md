## 3. 크레딧 $20 추가 이유 (간단 설명)

- AWS는 신규 계정에서 **Explore AWS 활동을 완료할 때 각 활동당 $20 추가 크레딧**을 제공함.
- 이번 $120 → $140 증가는 **AWS 탐색 활동 보상으로 추정**됨. 11/10 EC2 사용이 확인되어 *EC2 인스턴스 시작 활동* 보상일 가능성이 있지만, **어느 미션이 지급됐는지는 계정 크레딧 상세에서 아직 확인하지 못했음**.
- 지급 미션명·만료일은 AWS **Billing and Cost Management → Credits**에서 최종 확인 필요.
- 참고: [AWS 공식 추가 크레딧 안내](https://docs.aws.amazon.com/ko_kr/awsaccountbilling/latest/aboutv2/free-tier-plans-activities.html), [AWS 비용 튜토리얼($20씩 지급)](https://docs.aws.amazon.com/ko_kr/hands-on/latest/control-your-costs-free-tier-budgets/control-your-costs-free-tier-budgets.html).

## 4. Haven 기존 예산과의 관계

- **기존 승인된 프로젝트 운영 예산 $100은 변경하지 않음.** AWS Budgets 경보 $50/$80/$95도 그대로 유지.
- 이전 크레딧 $120은 **운영 $100 + 비상 예비 $20**으로 분리하여 계획했음.
- 새로 지급된 **추가 $20은 현재 미배정 여유 크레딧**으로 기록하고, 운영 예산/비상 예비비 증액 여부는 **팀장 협의 후 결정**.
- 즉, 현재 표시 기준 $140의 크레딧이 있어도 이 문서는 팀 전체 **승인 예산을 $140으로 변경하는 결재 문서가 아님**.
