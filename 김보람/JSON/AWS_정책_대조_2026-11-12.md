# AWS IAM 정책 JSON 대조 (2026-11-12)

## 비교 기준
- 원본: AWS CloudShell에서 추출한 `haven_iam_export.zip` (해당 시점 실제 IAM 정책)
- 비교 대상: GitHub `Boram` 브랜치의 `김보람/JSON`
- JSON 키 순서·공백은 무시하고 실제 필드·값을 비교함. AWS 관리형 정책의 전체 JSON은 ZIP에 포함되지 않으며 `attached.json`에 연결 내역만 기록됨.
- **AWS 권한·역할 자체는 변경하지 않음.**

## 현재 적용 중인 정책 중 GitHub에 동일한 JSON이 없었던 4종 — 원본 보관 완료
| 실제 AWS 정책명 | AWS 원본과 동일하게 추가한 GitHub 파일 | 기존 파일 관련 사항 |
|---|---|---|
| `Haven-Minsung-PassRole-Policy` | [31번](31_Haven-Minsung-PassRole-Policy.json) | 02번은 계정번호 변수 사용 |
| `Haven-EC2-S3-Backup-Restore` | [32번](32_Haven-EC2-S3-Backup-Restore.json) | 06번은 Sid/계정번호 변수 차이 |

| `Haven-Minsung-Delete-Policy` | [34번](34_Haven-Minsung-Delete-Policy.json) | 기존 13·15번과 달리 실제 AWS에서는 EC2 종료와 SG 삭제가 한 정책에 통합됨 |

- 기존 02·06·08·13·15번 등 과거 설계·기록 JSON은 **임의 덮어쓰기나 삭제 없이 그대로 보존**. 현재 AWS 구성과 일치하는 최신 원본은 31~34번을 확인할 것.
- 기존 GitHub JSON 28개 중 21개는 현재 적용 중인 AWS 고유 정책 또는 Haven EC2 역할 신뢰 정책과 내용이 일치하며, 동일 JSON이 여러 역할·사용자에 재사용될 수 있음. GitHub 28개 중 나머지 파일이 모두 현재 AWS에 연결된 정책이라는 뜻은 아님.

## 운영상 추가 확인
- 31번 PassRole 실제 AWS 정책은 **`haven-ec2-ssm-role`만** 허용함. `haven-ec2-web-role`로 `web-1` 역할 교체 시 민성님 PassRole 범위 수정이 필요한지 담당자와 확인. 이 문서는 IAM 정책을 수정하지 않음.
- AWS 내 `haven-ec2-ssm-role`과 `haven-ec2-web-role`의 IAM 신뢰 정책은 기존 [03번](03_Common_EC2_Trust.json)과 내용이 일치함.
- AWS 서비스 연결 역할 4개의 정책은 AWS 관리 범위이므로 사용자 지정 JSON 파일 추가 대상으로 처리하지 않음.
- ZIP의 정책은 **추출 시점 스냅샷**으로, AWS에서 이후 수정하면 다시 추출·대조해야 함.
