### 1회차 상세 작업 기록

1. 점검 대상

IAM 사용자: sherlocked (김보람이 생성한 별도 IAM 계정)

부여된 정책: AWSBillingReadOnlyAccess (비용 조회 권한)

액세스 키: 0개

2. 보안 설정

해당 사용자에게 MFA(추가 로그인 인증)가 등록되지 않은 상태를 확인함.

인증 관리자 앱을 이용해 MFA 등록 완료.

루트 계정과 IAM 사용자의 MFA가 별도로 관리되는 것을 확인함.

3. 권한 허용 시험

sherlocked 사용자로 AWS 콘솔 로그인 성공.

결제 및 비용 관리 화면 접속 성공.

이번 달 실제 사용 요금 $0.00 조회 성공.

4. 권한 거부 시험

IAM 사용자 정보 조회 시 iam:GetUser 권한 부족으로 접근 거부됨.

비용 관리 화면에서 이번 달 예상 비용 조회가 거부됨.

비용 이상 항목 상태 조회도 접근 거부됨.

따라서 비용 조회 정책이 적용되어 있지만 일부 비용 관련 정보에는 추가 권한 검토가 필요함.

5. 추가 확인 및 예정 작업

MFA 등록 후 로그인 시 추가 인증 요구 여부 재확인.

다른 팀원들의 AWS 작업 범위를 확인한 뒤 필요한 IAM 권한 설정.

권한별 허용·거부 시험을 진행하고 결과 기록.

검증 결과: 권한이 제한된 IAM 계정으로 비용 조회에 성공했으며, 허용되지 않은 IAM 사용자 정보 조회가 거부되는 것을 확인함.
