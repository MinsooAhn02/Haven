# AWS 유지 비용 예상 — 2026-11-23

**담당:** 김보람 (AWS 계정·IAM·비용 관리)  
**계산 기준일:** 2026년 11월 23일  
**예상 운영 기간:** 2026년 11월 24일 ~ 2027년 1월 11일 (49일)

## 1. 계산 기준

2026년 11월 23일 AWS Billing에서 확인한 누적 예상 사용 금액은 **$27.65**이다.

현재 AWS 크레딧은 총 $140이며, 프로젝트 운영 예산 $100과 비상 예비비 $40으로 구분되어 있다.

기존 운영 결정에 따라 다음 조건으로 유지 비용을 계산하였다.

- 리전: 서울(ap-northeast-2)
- EC2: t3.small 서버 2대
- EC2·NAT Gateway: 평일 오전 9시~오후 9시, 하루 12시간 운영
- 야간 및 주말: EC2 중지, NAT Gateway 삭제 및 관련 공인 IP 해제
- ALB·WAF: 24시간 유지 가정
- EBS 및 Route 53: 기존 자원 유지 가정
- 계산 기간: 평일 35일, 주말 14일
- 공휴일은 별도로 제외하지 않음

**주의:** 이 계산은 현재 운영 방식을 2027년 1월 11일까지 계속 유지한다고 가정한 예상 비용이며, 실제 운영 계획 확정을 의미하지 않는다.
