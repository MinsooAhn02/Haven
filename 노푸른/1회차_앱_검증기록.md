## 2026-11-11 · 실제 배포 사이트 오류 화면 추가 확인

- 환경: `https://orchestration-haven.cloud/` (사용자 보고, 실제 브라우저 확인)

| 확인 항목 | 시험 조건 | 기대 결과 | 실제 결과 | 판정 |
|---|---|---|---|---|
| 404 오류 화면 | `/__haven_404_probe_20261111__` 접근 | HTTP 404와 페이지를 찾을 수 없다는 안내 | HTTP 404. “페이지를 찾을 수 없습니다. 요청하신 페이지를 찾을 수 없습니다.” 표시 | 성공 |
| 403 접근 거부 화면 | 일반 회원 계정으로 `/admin/accounts/` 접근 | HTTP 403과 권한 거부 안내 | HTTP 403. “요청이 거부되었습니다. 이 요청을 처리할 권한이 없습니다.” 표시 | 성공 |
| 400 오류 화면 | 새 기록 작성에서 제목·내용을 비우고 저장 시도 | 서버에 요청이 전달되어 HTTP 400 응답 및 오류 화면 표시 여부 확인 | 브라우저가 “이 입력란을 작성하세요”라는 필수 입력 안내를 표시해 서버에 요청을 보내지 않음. HTTP 상태 코드와 공통 400 화면은 확인하지 못함 | 미시험 |

- 증거 범위: 실제 브라우저에서 확인했다는 사용자 보고를 기록함. 캡처 파일은 제공되지 않음.
- 400은 성공으로 판정하지 않는다. 브라우저의 필수 입력 검사를 통과해 서버 응답까지 확인하는 별도 시험이 필요하다.

## 2026-11-12 · 운영 사이트 공통 400 화면 확인

- 환경: 운영 사이트 `https://orchestration-haven.cloud`, 본인 일반 회원 계정으로 본인 글 상세 페이지에 접속
- 시험: 개발자도구에서 첨부 파일 input에 `multiple` 속성을 임시로 추가한 뒤, 테스트 파일 2개를 동시에 선택해 업로드
- 실제 결과: `오류 코드 400`, `요청 내용을 확인해 주세요` 공통 오류 화면 표시
- 판정: 공통 400 화면 확인 완료
- 개발자도구에서 속성을 임시 추가했으므로 소스 코드 수정은 없음
