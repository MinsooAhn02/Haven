## 7. 템플릿이 없을 때 (CI 영향)

`HAVEN_TEMPLATES_DIR`를 지정하지 않으면 기본 경로 `노푸른/templates`를 쓴다. 이 폴더는 현재 저장소에 없다. 그 상태로 시험하면 **Ran 65, FAILED (failures=13, errors=32)**이고, 64건의 오류 메시지에 `TemplateDoesNotExist`가 포함된다. 404·403 시험도 어떤 템플릿을 썼는지까지 확인하므로 함께 실패한다.

따라서 앱 PR의 실제 GitHub CI는 노푸른 템플릿이 main에 들어오거나, 시험용 템플릿 방식이 정해져야 통과한다(노푸른 답변서 6-4, 안민수 결정).

## 9. Windows PC에서 재현하는 방법

저장소 루트(`C:\dev\Haven`)의 PowerShell에서 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File 안민수\dev-db-setup.ps1   # 끝에 OK 4줄 확인
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r 안민수\앱통합_초안\requirements.txt

cd 신요찬\app
$env:DJANGO_SECRET_KEY = "<로컬 개발용 임의 문자열>"
$env:DJANGO_DEBUG = "1"
$env:DJANGO_ALLOWED_HOSTS = "127.0.0.1,localhost"
$env:DB_NAME = "haven_dev"; $env:DB_USER = "haven_owner"; $env:DB_HOST = "localhost"; $env:DB_PORT = "5432"
# DB_PASSWORD는 넣지 않는다 (pgpass.conf에서 읽음)

python manage.py check
python manage.py migrate
python manage.py test accounts posts -v 2
```

노푸른 템플릿이 없으면 7장처럼 시험이 실패한다. 그 전까지는 시험용 템플릿 폴더를 `$env:HAVEN_TEMPLATES_DIR`로 지정해야 한다. 이 폴더는 저장소에 넣지 않는다.
