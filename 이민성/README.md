# 1. AWS 클라우드 환경 구축 및 서비스 확장
## 필수
---
AWS EC2를 활용하여 클라우드 서버를 구축하고, Web 및
DB 서비스를 구성하여 클라우드 기반 서비스 운영 환경을
구현한다.
---
## 도전
---
도메인을 연결하고 메일, DNS 등 외부 서
비스를 연동하여 클라우드 서비스의 접근
및 운영 환경을 확장한다.
